3. Algorithm Details
3.1 Range Calculation Algorithm
python
def calculate_range_from_point():
    Inputs:
        - current_battery_kwh
        - efficiency_kwh_per_km
        - battery_capacity_kwh
        - terrain_factor
        - weather_factor
    
    Calculations:
        1. Effective efficiency = base_efficiency × terrain_factor × weather_factor
        2. Max distance = current_battery_kwh ÷ effective_efficiency
        3. Safe distance = max_distance × 0.8 (safety buffer)
        4. Usable battery = current_battery_kwh
        5. Full charge range = battery_capacity ÷ base_efficiency
3.2 Station Filtering Algorithm
python
def filter_nearby_stations():
    1. Query stations within geographic radius
    2. For each station:
        - Calculate haversine distance
        - Check if within safe_range
        - Calculate energy required to reach
        - Check if reachable with current battery
    3. Sort by distance
    4. Return top 5 stations
